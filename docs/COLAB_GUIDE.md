# Google Colabへの進み方

## 1. アプリからコードを保存する

レッスンまたは作曲スタジオで **.py保存** を押します。現在編集しているPythonコードが保存されます。

## 2. スターターノートブックを開く

Lesson 7のボタンからスターターノートブックを開き、上から順にセルを実行します。

## 3. 自分のコードを貼り付ける

ノートブックの「自分の曲を書く」セルへ、保存したコードを貼り付けます。ブラウザ版と同じ曲データを作り、ピアノロールや音声へ変換します。

## 4. ブラウザ版との違いを確かめる

ブラウザ版はWeb Audioで音を再生します。Colab版では、NumPyで簡単な波形を計算して音声を作ります。同じ曲データでも、再生方法を交換できることが重要です。

## 5. 発展させる

次の順序で変更すると、原因と結果を追いやすくなります。

1. 変数の値を変える
2. リストの要素を変える
3. `for`の回数を変える
4. `if`の条件を変える
5. 自分の関数を作る
6. Matplotlibで図を追加する
7. 数値データを音へ変換する
