# Google Colabへの進み方

## 1. アプリからコードを保存する

中央のコードエディタ上部にある **.py保存** を押します。現在のレッスンで編集したコードが保存されます。

## 2. スターターノートブックを開く

`colab/caya_starter.ipynb`をGoogle Colabで開き、上から順にセルを実行します。最初の準備セルが、公開サイトから教育用作曲APIを読み込みます。

## 3. コードを貼り付ける

ノートブックの「自分の曲を書く」セルへ、アプリで保存したコードを貼り付けます。`export_song()`で曲データを取り出し、ピアノロールと音声へ変換します。

## 4. ブラウザアプリとの違いを確認する

ブラウザアプリでは、Tone.jsが音を鳴らします。Colabでは、NumPyで簡単な波形を計算して音声を作ります。同じ曲データでも、再生方法を交換できることが重要です。

## 5. 独自のコードへ発展させる

次の順序で変更すると、原因と結果を追いやすくなります。

1. 変数の値を変える
2. リストの要素を変える
3. `for`の回数を変える
4. `if`の条件を変える
5. 自分の関数を1つ作る
6. 別のデータを音へ変換する
