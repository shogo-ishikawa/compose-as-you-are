# 授業利用ガイド

## 100分講義の例

| 時間 | 活動 | Pythonの焦点 |
|---:|---|---|
| 0–10分 | 完成例を再生し、テンポと音色を操作する | コードと結果の対応 |
| 10–25分 | Lesson 1・2 | 関数、文字列、数値、変数 |
| 25–40分 | Lesson 3 | リスト、添字、`len` |
| 40–58分 | Lesson 4 | `for`、`range`、インデント |
| 58–75分 | Lesson 5 | `if`、`else`、`%` |
| 75–88分 | Lesson 6 | 乱数、`seed`、再現性 |
| 88–97分 | 個人またはペアで短い作品を作る | 文法の組合せ |
| 97–100分 | `.py`保存とColab教材の案内 | 次の学習への接続 |

Lesson 7は、全員が同じ時間内に完了することを求めず、グループワークへ進む学生の入口として扱います。

## 初心者への支援

- 最初は変更箇所を1行または1値に限定します。
- 音だけで判断させず、ピアノロールとイベント表も確認させます。
- エラーが出た場合は、元のPythonエラーを消さず、日本語の補助説明と対応させます。
- 完成した曲の巧拙よりも、コードと結果の関係を説明できることを重視します。

## 経験者への発展課題

- 重み付き乱数で音の選択確率を変える
- 前の音から次の音を決めるマルコフ連鎖
- 三角関数、素数、漸化式から音列を作る
- 複数トラックの役割を関数へ分ける
- 観測値や測定値を音高、長さ、強さへ割り当てる
- Colab上で波形やスペクトルを解析する

## 確認の観点

短い作品発表では、次の観点を使えます。

- 使用したPython文法を説明できる
- 変更したコードと音の変化を対応付けられる
- 自動作曲の規則を日本語で説明できる
- 同じ条件で結果を再現できる
- 他者の作品を聞き、具体的な改善案を述べられる
