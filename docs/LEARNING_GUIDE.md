# 学習ガイド

この教材は、授業のnotebookやLAVi-SPICAで学んだ文法を音楽へ応用するためのものです。授業の最後に例題を見る使い方と、後から自分で練習を進める使い方の両方ができます。

## 学ぶ順番

1. 変数と計算で音の長さを決める。
2. リストから音を取り出す。
3. forとrangeで音を繰り返す。
4. ifで音・休符・アクセントを選ぶ。
5. 関数でデータを作り、返り値を確かめる。
6. 乱数とseedで再現できる音列を作る（選択発展）。
7. 音の部品を重ね、小作品へ進む（選択発展）。

Lesson 6はSPICAの第6回と同じ内容ではありません。乱数を使った追加の応用です。必要な文法は各レッスンの「LAVi-SPICAで文法を見直す」から確認できます。

## 例題・練習・発展の違い

例題は完成コードを読み、結果を予想して実行するためのものです。練習問題では式や処理を自分で書き、発展問題では関数や複数の処理を組み立てます。`...`を対応するPythonコードで置き換えてください。`# TODO`というコメントは残せます。

困ったときはヒント1から順に開きます。解答例は自分のコードと比較する資料です。解答例を開く操作は、コードの上書きや条件確認済みの記録にはなりません。

## 実行結果を読む

「Pythonを実行・答え合わせ」を押すと、まずコードが実行できるかを調べ、その後、課題ごとの条件を確認します。未完成の箇所、Pythonの実行エラー、実行できるが条件を満たさない状態、確認システム側のエラーを分けて表示します。

条件ごとの期待値と実際の値を比べ、1項目ずつ修正してください。関数は、例題と異なる引数でも確かめます。音楽の好みや作品の説明文は自動採点しません。

## 記録を失わないために

問題ごとのコードは自動保存します。「開始コードへ戻す」前には確認が出て、直前のコードを退避します。「直前のコードを復元」で戻せます。

保存できない警告が出た場合は、画面を閉じる前に学習記録を書き出してください。学習記録は別端末でも読み込めます。旧レッスンのデータは別に保管され、旧レッスン画面から開けます。

## 音が出せない場合

音声再生は必須ではありません。ピアノロール、イベント表、拍数を使って確認できます。再生するときは小さめの音量から始めてください。
