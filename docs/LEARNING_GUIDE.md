# 学習ガイド

## この教材の考え方

Compose As You Areでは、Python文法を暗記してから作品を作るのではなく、短いコードを音として確かめながら文法を学びます。

基本の進め方は次の循環です。

```text
コードを読む
  ↓
1か所だけ変える
  ↓
Pythonを実行する
  ↓
音・ピアノロール・表を比べる
  ↓
変化を言葉で説明する
```

複数の場所を一度に変更すると、どの変更が結果へ影響したか分かりにくくなります。最初は必ず1か所ずつ変更してください。

## 音名の読み方

アプリでは、音名を次のような文字列で書きます。

```python
"C4"   # ド
"D4"   # レ
"E4"   # ミ
"F#4"  # ファのシャープ
"Bb3"  # シのフラット
```

先頭の英字が音の名前、末尾の数字がおおよその高さを表します。数字が大きいほど高い音です。

## 長さの読み方

この教材では、数値の`1`を1拍として扱います。

```python
add_note("C4", 0.25)  # 4分の1拍
add_note("C4", 0.5)   # 半拍
add_note("C4", 1)     # 1拍
add_note("C4", 2)     # 2拍
```

## 代表的な作曲用関数

### 曲を始める

```python
start_song(
    tempo=108,
    instrument="pluck",
    title="私の曲"
)
```

- `tempo`：1分間の拍数
- `instrument`：音色
- `title`：曲名

### 音を追加する

```python
add_note("C4", 1)
```

3つ目の値を加えると、音の強さを0から1の範囲で指定できます。

```python
add_note("C4", 1, 0.7)
```

### 休符を追加する

```python
add_rest(0.5)
```

### 和音を追加する

```python
add_chord(["C4", "E4", "G4"], 2)
```

### トラックを追加する

```python
new_track("bass", instrument="bass")
add_note("C2", 2)
```

## 学習記録の例

コードを変更した後は、次の3点を短く記録すると理解が深まります。

1. どの行を変更したか
2. 音や図がどう変わったか
3. その理由をPython文法と結び付けてどう説明できるか

例：

> `range(4)`を`range(8)`へ変更した。音の数が4個から8個へ増えた。`range(8)`が0から7までの8個の整数を作り、`for`の中の`add_note`が8回実行されたためである。
