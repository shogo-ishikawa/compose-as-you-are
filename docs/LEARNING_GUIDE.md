# 学習ガイド

## 学び方の基本

Compose As You Areでは、文法を暗記してから作品を作るのではなく、短いコードを音として確かめながら学びます。

```text
コードを読む
  ↓
1か所だけ変える
  ↓
Pythonを実行する
  ↓
音・ピアノロール・表を比べる
  ↓
変化の理由を説明する
```

複数の場所を一度に変更すると、どの変更が結果へ影響したか分かりにくくなります。最初は必ず1か所ずつ変更してください。

## 例題・練習問題・発展問題

各レッスンには3段階のコード課題があります。

### 例題

新しい文法の働きを確認するコードです。上から読み、指定された小さな変更を加えます。

### 練習問題

初期コードを自分で変更して目的を達成します。少なくとも1か所変更してから実行してください。

### 発展問題

複数の文法や音楽上の考え方を組み合わせます。任意課題ですが、グループワークへ進むための良い出発点になります。

例題と練習問題を実行すると、そのレッスンが完了として記録されます。

## 音・図・表を使い分ける

### 音

曲全体の印象、テンポ、反復、強弱、音色の違いを確認します。

### ピアノロール

横方向は時間、縦方向は音の高さです。音符がない場所は休符または空白です。

### イベント表

開始位置、音名、長さ、強さ、トラックを数値として確認します。`for`の回数や`if`の条件を検証するときに便利です。

## 学習記録の書き方

次の3点を短く記録すると、理解が深まります。

1. どの行を変更したか
2. 音や図がどう変わったか
3. その理由をPython文法と結び付けてどう説明できるか

例：

> `range(4)`を`range(8)`へ変更した。音の数が4個から8個へ増えた。`range(8)`が0から7までの8個の整数を作り、`for`の中の`add_note`が8回実行されたためである。

## エラーの扱い方

エラーが出たら、すぐに元へ戻す前に次の順で読みます。

1. エラー名を確認する
2. 行番号付近を見る
3. 日本語の手掛かりを読む
4. 直前に変更した1か所を確認する
5. 修正してもう一度実行する

エラーを修正した過程も、Pythonを学んだ記録です。
