# 作曲スタジオガイド

## ステップシーケンサー

16個のステップが左から右へ時間順に並びます。

- 旋律・低音：クリックで次の音、Shift＋クリックで前の音、右クリックで無音
- Kick・Snare・Hi-hat：クリックでオン・オフ
- 和音：4ステップごとに選択

## 1ステップの長さ

- `0.25`拍：細かく速い動き
- `0.5`拍：扱いやすい基本設定
- `1`拍：ゆっくりした音の並び
- `1/3`拍：三連符

三連符では、3ステップで1拍になります。

## ミキサー

### 音量

トラックごとの音量です。複数トラックを重ねると全体が大きくなるため、最初は60〜80%程度から調整します。

### パン

左右の位置です。`-1`が左、`0`が中央、`1`が右に対応します。極端に分ける前に、小さく動かして比較してください。

### 音色

旋律、和音、低音ごとに音色を選べます。音高やリズムが同じでも、音色によって印象が変わります。

## Pythonコードへの変換

シーケンサーを変更すると、同期中はPythonコードも更新されます。コードを直接編集すると自動同期が止まります。

- 手動編集を残す：`.py保存`を使う
- シーケンサーを優先する：`シーケンサーをコードへ反映`を押す

生成コードでは、各ステップの位置を`beat=i * step`として表します。空のステップは`None`です。

## 作品を整える順序

1. 旋律だけで短いループを作る
2. 低音を4ステップごとに置く
3. KickとSnareで拍を作る
4. Hi-hatで細かい動きを加える
5. 和音を加える
6. 音量とパンを調整する
7. Pythonコードへ独自の条件や関数を加える

一度に全てを変更せず、1トラックずつ再生して役割を確認してください。
