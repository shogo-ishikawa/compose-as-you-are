# 自動作曲ガイド

## 自動作曲とは

自動作曲は、プログラムが何もないところから勝手に名曲を作ることではありません。人が材料と規則を設計し、プログラムがその規則を繰り返し適用して音を並べます。

## 4つの設計要素

### 1. 材料

使う音、リズム、音色、和音を決めます。

```python
scale = ["C4", "D4", "E4", "G4", "A4"]
```

### 2. 規則

順番、反復、条件、確率を決めます。

```python
for i in range(16):
    note = scale[i % len(scale)]
    add_note(note, 0.5)
```

### 3. 制約

音域を狭くする、最後の音を固定する、隣の音へだけ移動するなど、候補を絞ります。制約は自由を減らすだけでなく、曲へ統一感を与えます。

### 4. 構造

A–B–A、導入・展開・終結、小節ごとの変化など、時間全体の形を作ります。

## 乱数を使わない自動作曲

- リストを順番に循環する
- 数列を音高へ変換する
- 条件分岐で周期的な休符を入れる
- 二重ループで小節構造を作る

これらも、プログラムが規則に従って音を生成する自動作曲です。

## 乱数を使う自動作曲

乱数を使う場合も、候補を人が設計します。

```python
random.seed(42)
for i in range(16):
    note = random.choice(scale)
    add_note(note, 0.5)
```

候補リスト、選択確率、音域、終止音を変えると、生成結果の性格が変わります。

## 再現性

同じseed、同じコード、同じ入力を使うと、同じ乱数列を再現できます。作品の比較、共同制作、実験結果の検証に重要です。

## データの可聴化

数値データを音高、長さ、強さへ割り当て、データを音として調べる方法です。

- 値が大きいほど高い音
- 変化量が大きいほど強い音
- 時刻を音の開始位置へ対応

単に美しい曲を作るだけでなく、データの傾向や異常を別の感覚で捉える目的にも使えます。
